## ⚠️ Disclaimer

EZZ TOOLS is intended for educational purposes, authorized security testing, and lawful use only.

Only use these tools on systems, networks, accounts, and data that you own or have explicit permission to analyze. Unauthorized access, privacy violations, and malicious activity are not permitted.

## 📝 Description

EZZ TOOLS is a command-line toolkit designed to centralize multiple cybersecurity and system utilities in one interface.

### ✨ Features

- 🖥️ **Interactive CLI** — Terminal-based menu and configuration.
- 🔎 **OSINT** — Research using publicly available information.
- 🌐 **Network diagnostics** — IP lookup, ping and host discovery.
- 🔐 **Security testing** — Authorized port scanning and website security checks.
- 👤 **Username research** — Search for publicly accessible profile information.
- 📧 **Email and phone utilities** — Public-data lookup where supported.
- 📁 **File utilities** — Inspect and manage file metadata.
- ⚙️ **Configuration** — Centralized settings and customizable options.

*Feature availability depends on the modules, external services and dependencies included in the installed version.*

## ⚙️ Installation

### Requirements

- Windows or a compatible Linux environment
- Python installed
- Git (optional, for cloning the repository)
- Required Python dependencies

### Windows

**1. Download the project**

Download the ZIP from the GitHub repository and extract it.

**2. Open the project folder**

Open a terminal in the extracted directory.

**3. Install dependencies**

Use the dependency installation instructions included with the project.

**4. Configure the tool**

```bash
python setup.py
```

**5. Launch EZZ TOOLS**

```bash
python redtiger.py
```

The current source entry point is still named `redtiger.py`. It can be renamed after verifying that all imports, paths and launch scripts continue to work.

## 🧰 Usage

Launch the interactive interface:

```bash
python redtiger.py
```

Follow the menu instructions to select an available utility.

Use only authorized targets when running security diagnostics or scans.
